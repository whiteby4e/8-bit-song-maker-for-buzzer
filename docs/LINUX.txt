8-bit Song Maker for Buzzer - Linux
===================================

Open a terminal in the project folder.

Check Python:
python3 --version

Run the song maker:
python3 src/song_maker.py

MIDI converter:
python3 src/chiptune_converter.py music/Virtual_Insanity.mid -o examples/virtual_insanity/song.h

Optional executable mode:
chmod +x src/song_maker.py src/chiptune_converter.py

Then:
./src/song_maker.py
