8-bit Song Maker for Buzzer - Linux
===================================

Open a terminal in the project folder.

Check Python:
python3 --version

Run the song maker:
python3 src/song_maker.py

Install the MIDI dependency:
python3 -m pip install mido

Generate the MIDI example header:
python3 src/chiptune_converter.py music/Virtual_Insanity.mid -o examples/midi/song.h

The generated song.h is local build output and is intentionally not committed.

Optional executable mode:
chmod +x src/song_maker.py src/chiptune_converter.py

Then:
./src/song_maker.py
