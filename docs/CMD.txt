8-bit Song Maker for Buzzer - Windows CMD
==========================================

Open CMD in the project folder.

Check Python:
python --version

Run the song maker:
python src\song_maker.py

If "python" is not recognized:
py --version
py src\song_maker.py

Install the MIDI dependency:
python -m pip install mido

Generate the MIDI example header:
python src\chiptune_converter.py music\Virtual_Insanity.mid -o examples\midi\song.h

The generated song.h is local build output and is intentionally not committed.
